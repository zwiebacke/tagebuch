# Trink-Tagebuch (App zum Selbst-Hosten)

Dateien: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

## GitHub Pages
1. Auf github.com ein neues öffentliches Repository anlegen (z. B. "tagebuch").
2. Alle Dateien aus diesem Ordner hochladen ("Add file" > "Upload files"), direkt ins Hauptverzeichnis.
3. Settings > Pages > Branch "main", Ordner "/ (root)" > Save.
4. Nach ca. 1 Minute ist die Seite unter https://DEIN-NAME.github.io/tagebuch/ erreichbar.

## Aufs Handy
- iPhone: Link in Safari öffnen > Teilen > "Zum Home-Bildschirm".
- Android: Link in Chrome öffnen > Menü > "App installieren" / "Zum Startbildschirm hinzufügen".
Einmal online öffnen, danach läuft die App auch offline.

## Hinweise
- Daten liegen nur auf dem jeweiligen Gerät. Regelmäßig unter "Export" ein JSON-Backup speichern.
- Nach Änderungen an index.html in sw.js die Version (V='tagebuch-v1') hochzählen.
